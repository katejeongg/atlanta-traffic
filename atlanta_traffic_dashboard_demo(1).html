ATL / IN MOTION

Important: This file is a self-contained coded design prototype, not an empirical analysis of Atlanta. It uses a fixed pseudorandom dataset and simplified road traces. Counts, volume curves, timing, location patterns and severity rates are fictional. In the real project, use cleaned crash IDs and geocoordinates from GDOT, and pair traffic counts only with appropriate stations, road directions, locations and dates from TMAS.

Design approach: direct spatial encoding, a weekly temporal matrix, aligned time-series, collision composition rings, road/time dot swarms, and a corridor time–distance matrix. Six coordinated views, with state shared across the page. Built in HTML, CSS, JavaScript and SVG; no CDN required.
