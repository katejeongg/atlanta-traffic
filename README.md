# Atlanta Traffic — Beyond the Crash Count

View the webpage here: [https://katejeongg.github.io/atlanta-traffic/](https://katejeongg.github.io/atlanta-traffic/)

## How to Run

run **one** of the methods below at folder root:

### Option 1: Python http.server (Recommended)

```bash
python3 -m http.server
```

Navigate to [http://localhost:8000](http://localhost:8000)

### Option 2: Node.js (`npx`)

```bash
npx serve
```

or

```bash
npx http-server
```

Then open the local URL printed in your terminal (typically [http://localhost:3000](http://localhost:3000) or [http://localhost:8080](http://localhost:8080)).
